# 🎫 Qusai Final Frontend – Ticketing & Registration System

## 📌 Project Overview
- 🧍‍♂️ Attendees can browse and search free events.
- 🎟️ Attendees can register for tickets.
- ✉️ Attendees receive confirmation emails with QR codes.
- 🧑‍💼 Event Organizers can manage ticket inventory.

## ⚙️ Tech Stack
- React + Vite  
- Bootstrap 5  
- Axios  
- Google Fonts (Actor)  
- React Toastify
