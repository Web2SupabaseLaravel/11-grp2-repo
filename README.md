# 🛠️ Qusai Final Backend – Ticketing & Registration System

This is the official **Laravel backend** for the Ticketing & Registration System built as part of our graduation project.

---

## 📌 Features

- 🎟️ Event creation and listing
- ✅ Ticket registration with email confirmation
- 📩 Automatic QR code generation for tickets
- 🧑‍💼 Role-based access (Admin, Organizer, Attendee)
- 🗃️ Supabase PostgreSQL integration

---

## ⚙️ Tech Stack

- Laravel 10+
- PostgreSQL (via Supabase)
- Laravel Sanctum (optional)
- Mailtrap (email testing)
- QR Code Generator
