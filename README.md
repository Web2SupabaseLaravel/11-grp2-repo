## 🎟️ Laravel Event Registration Management System

Welcome to **Laravel Event Registration Management System**, a clean and efficient Laravel application to manage user registrations for events.

---

## 🎯 Project Overview

This system enables users to register for events by linking User IDs and Event IDs with additional details such as registration status and exact registration timestamp. It ensures data integrity and provides a smooth user experience.

---

## ⚙️ Technologies Used

- **Laravel 12** – PHP Framework  
- **Blade Templates** – For frontend views  
- **PostgreSQL (Supabase)** – Cloud-hosted database  
- **HTML & CSS** – Styling and layout  


---

## 🧾 Key Features

- Register users for events by selecting existing User ID and Event ID  
- Specify registration status: Confirmed, Cancelled, Transferred  
- Record registration date and time with precision  
- Server-side validation for data accuracy  
- Responsive and user-friendly interface  
- Actions for editing and deleting registrations



## 🚀 Usage
- Access the application at http://localhost:8000/events
- Add new event registrations
- Edit or delete existing registrations easily via action buttons
